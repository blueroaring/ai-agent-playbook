# 09 · Godot 自动化：无头、录帧、编辑器桥与端口探测

> **适用范围**：机制 `[通病]`（无头不渲染、点号目录不被扫描、UndoRedo 语义）；
> 具体版本/端口占用 `[本机]`。
> **谁该读**：要让 Agent 帮忙改 Godot 项目、生成素材、验证画面的开发者。
> **配套代码**：`recipes/godot-mcp/`（CLI 桥 + 编辑器插件桥）。

## 1. 无头模式**没有渲染** —— 要画面必须用 Movie Maker `[通病]`

### 症状

用无头（`--headless`）跑项目做自动化测试，一切正常、退出码 0，
但**你截不到任何有意义的画面**，`get_viewport().get_texture()` 之类拿不到真实内容。

### 根因

**`--headless` 使用哑渲染驱动**：它保证脚本能跑、场景能加载、逻辑能执行，
但**不产生真实绘制**。这是特性不是缺陷——它让 CI 能在没有 GPU 的机器上跑逻辑测试。

### 解法：Movie Maker 模式录真实帧

Godot 支持把真实渲染帧写成 PNG 序列（`--write-movie` 系列参数）。
`[本机]` 的实现把它封成了一个工具（`godot_frames`），参数是"帧数 / fps / 输出目录"。

**实测**：在带独显（RTX 4050）的机器上录到了 `1152×648` 的**真实渲染帧**。

**代价（必须提前告知用户）**：Movie Maker 会**短暂弹出游戏窗口**（因为它需要真实窗口/渲染上下文）。
"后台静默截图"是做不到的。**涉及会弹窗的操作，先说再做。**

### 分工建议

| 目的 | 用什么 |
|---|---|
| 逻辑测试、脚本语法检查、加载错误 | **无头**（快、无窗口） |
| 导出前的构建验证 | **无头** |
| **"画面里到底有没有那个东西"** | **Movie Maker 录帧** |

→ 为什么"录帧"这一步不可替代：见 [01](01-verification-discipline.md) 第 2 问（验证要走到"人眼可见的画面变化"）。

## 2. 资产生成：程序化造 PNG，然后**必须重新导入** `[通病]`

Agent 帮不上"手绘"的忙，但**程序化生成素材**是很实际的一条路。

`[本机]` 实测流程（用 `godot_script` 跑一段 GDScript）：

```gdscript
var img := Image.create(64, 64, false, Image.FORMAT_RGBA8)
# …逐像素或渐变填充…
img.save_png("res://art/gradient.png")
```

**关键点**：

1. 写进 `res://` 后，**新资源不会自动进资源库** → 必须触发一次**重新导入**（`godot --import` / 编辑器扫描），
   否则场景里引用不到它
2. 导入是**有产物的**：去看 `.godot/imported/` 或直接看资源面板——**别只看"文件已写入"**
3. 生成的图**要人眼看过**才算验证（→ 录帧 / 直接看 PNG）

**适用边界**：渐变、色块、图标、tile、程序化纹理、占位图 —— 这些能生成；
**原创美术设计**不是脚本能替代的。别给出"我可以帮你画任何素材"这种承诺。

## 3. 端口探测陷阱：**8080 那类端口永远不要假设它是空的** `[本机]`→`[通病]`

### 症状

编辑器插件（或任何本机服务）**首次绑端口失败**；更糟的是**你的端口探测逻辑也被骗了**，
导致你确信"这个端口是空的"。

### 根因

`[本机]` 实测：**`9080` 被机器自带的音频服务（`NahimicService`）占用**。
它不是 web 服务，所以：

- 你按"能不能连上 HTTP"来探测 → 连不上 → 误判为空闲
- 但 `bind()` 会因为端口已被监听而失败

**"探测"和"实际使用"的判据不一致**，就会得到"明明空着却绑不上"。

### 解法：不要固定端口，让插件自己挑并**把结果写下来**

`[本机]` 的方案（值得直接抄）：

```
1. 插件启动时在 [9080, 9090] 区间内逐个尝试 bind
2. 挑到空闲端口后，把**实际端口写到 user://<bridge>_port.txt**
3. 客户端（MCP 服务）**优先读这个文件**，而不是猜端口
4. 只有在文件不存在时，才回退到逐个探测
```

**为什么"写文件"这一步是精髓**：
探测是**猜测**，端口文件是**事实**。这跟 [08](08-lan-reverse-proxy-remote-gui.md) 第 6 节
的 token 文件是同一个模式：**"会变的东西"只有一个权威来源**。

### 验证

```powershell
# 谁真的占着这个端口（不要只看能不能连上 HTTP）
Get-NetTCPConnection -LocalPort 9080 -State Listen | Select-Object OwningProcess
Get-Process -Id <上面的 PID> | Select-Object Name,Path
```

**排端口问题时永远走 TCP 监听表这一步**，不要用"能不能访问"来推断"有没有被占"。

## 4. 编辑器桥：让 Agent 在**打开的场景**里动手 `[通病]`

两种集成形态，各有明确的适用面：

| 形态 | 能做什么 | 不能做什么 |
|---|---|---|
| **CLI 桥** | 建项目、语法检查、无头跑 N 帧、录帧、导入、导出 | 改不了**当前正在编辑**的场景 |
| **编辑器插件桥** | 读当前场景树、增删节点、改属性、保存场景、运行/停止 | 需要编辑器开着，且只对当前编辑的场景有效 |

`[本机]` 两个都做了，并注册成同一组工具（CLI 侧 20 个上下）。
**这是正确做法**：不要试图用一种形态覆盖全部需求。

### 编辑器操作的语义：**全部走 UndoRedo** `[通病]`

`[本机]` 的实现要点：插件的每个改动（增节点、删节点、改属性）都**包在 UndoRedo 事务里**。

**为什么这很重要**：Agent 改错了，用户可以 **Ctrl+Z 撤销**。
如果直接改节点，Agent 的修改与用户的手动修改**混在一起且不可逆**，
用户会不敢让你碰他的场景。

> 📌 **通用原则**：**Agent 对用户资产做修改时，要尽量走宿主的"可撤销"通道。**
> 这比"我很小心"更能建立信任。

## 5. 临时文件：用**点号前缀**避开资源扫描 `[通病]`

`[本机]` 的做法：`godot_script` 在项目里建 `.dsh_tmp/` 放临时脚本，执行完即删。

**为什么用点号开头**：Godot（以及很多工具链）**默认忽略以 `.` 开头的目录/文件**，
所以临时文件不会被当成资源去扫描/导入，不会污染项目、不会触发无谓的导入。

**这条模式到处适用**：临时目录加 `.` 前缀（或放到系统 temp）是"别让工具看见我的草稿"的通用手法。

## 6. 验证：一次完整的**视觉闭环**（值得作为范本）

`[本机]` 实测的端到端验证链条 —— **注意它经过了三个独立的观测面**：

```
① 编辑器里新增一个 ColorRect
        ↓
② 改 position / size / color
        ↓
③ 保存场景
        ↓
④ 读磁盘上的 main.tscn → 里面真的出现了这个节点（面 1：磁盘）
        ↓
⑤ 录帧 → 画面里真的出现了这个青色方块（面 2：画面）
```

**为什么这叫闭环**：任何一步做错了，后面的观测面就会露馅：

| 如果… | 会怎样 |
|---|---|
| 插件只是"以为改了" | 磁盘上的 `.tscn` 里没有节点 |
| 保存的是别的场景 | 磁盘文件不变 |
| 改了但没渲染 | 画面里没有方块 |
| 采集到的是旧帧 | 画面里没有方块 |

**单看任何一面都不够** —— 这正是 [01](01-verification-discipline.md) 反复强调的
"验证要走到端到端副作用"。

## 7. 其他实测注意点

- **导出需要导出模板**：没装模板时导出会失败。先确认模板版本与编辑器版本一致。
  `[本机]`：编辑器 4.7.2 stable（Steam 版），导出模板 4.7.2.stable 已装
- **控制台中文乱码**：PowerShell 控制台显示 Godot 的中文日志会乱码——**显示层问题，数据是好的**
  （→ [02](02-windows-powershell51.md) 第 6 节）
- **没有项目时先建一个示例项目**：用来验证"能力真的通了"，
  比在用户的正式项目上试错安全得多
- **Steam 版路径**：可执行文件在 Steam 库目录下，路径含空格 → **引号别漏**，
  且这类"工作区外的可执行文件"在受限沙箱里可能被拒（→ [03](03-sandbox-stdio-limits.md)），
  所以应当**由宿主侧的 MCP 服务去调用它**

## 8. 速查

| 现象 | 首查 |
|---|---|
| 无头跑没画面 | 正常。要画面用 **Movie Maker 录帧**（会弹窗） |
| 端口绑不上但"探测时空闲" | 用 `Get-NetTCPConnection -State Listen` 看**真实占用**；改**自动挑端口 + 写端口文件** |
| 新生成的素材引用不到 | **重新导入**（`--import`）了吗？ |
| 编辑器改了场景没生效 | 保存了吗？看**磁盘上的 `.tscn`** |
| Agent 改了我的场景 | 实现是否走 **UndoRedo**？（可 Ctrl+Z） |
| 临时文件污染项目 | 用 `.` 前缀目录，或放系统 temp |
| 导出失败 | 导出模板装了吗？版本对得上吗？ |
